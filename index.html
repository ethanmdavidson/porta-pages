porta-pages

Small apps that are each a single, self-contained HTML file. Use them here, or save one and open it from disk, offline.

  • Conjunction A game of stalking a satellite. Fly an autonomous interceptor in low Earth orbit, under real orbital mechanics, and get close enough to strike before the target sees you coming.
  • Emergency binder Medical information, emergency contacts, insurance numbers and documents in one file that works offline. The file saves a copy of itself with your information inside.
  • Girih A tile-laying puzzle built on the five girih tiles of Persian strapwork.
  • I Ching Cast a hexagram and read it. The full text of the Book of Changes is included, in Chinese, in James Legge's English translation, and in modern English.
  • Oblique Engineering A deck of prompts for getting unstuck on software problems, after Brian Eno and Peter Schmidt's Oblique Strategies.
  • Peer-to-peer file transfer Send files straight between two devices on the same network, with no server. Connect them by scanning or pasting two short codes.
  • Sealed letter Seal a message into a new HTML file that decrypts itself, with a passphrase or with share cards held by people you trust, any few of which open it together.
  • Step Sequencer A drum machine and synth where every sound is synthesized and the whole song is saved in the link. Share the address to share the song, and press Back to undo.
  • Baseline tracer Runs an app and records which web platform features it calls, then sorts them by how widely available they are. Needs a network connection on the first visit.
  • Web features for a self-contained HTML file Which web platform features can be relied on in a single HTML file opened from disk. Needs a network connection on the first visit.
  • Should I open the windows? Compares indoor and outdoor air by heat and moisture, and estimates what letting it in would cost or save with your air conditioner or dehumidifier.
  • Workbench Checks porta-pages apps against the repo's conventions, using only the browser. Pick the repo folder, drop in some files, or enter URLs.
