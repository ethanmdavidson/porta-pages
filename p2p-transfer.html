    How it works, and its limits

    The devices connect with WebRTC, the same technology video calls use. To connect, each browser needs a few facts about the other: its network addresses, a password for the connection, and the fingerprint of its encryption key. Normally a server passes these along. Here, you do, as the two codes.

    There is no STUN or TURN server either, so the devices can only connect when they can reach each other directly, which usually means the same local network. Some guest and public Wi-Fi networks stop devices from reaching each other, and then this won't connect.

    Files go directly between the devices, encrypted. Each one is checked with SHA-256 on arrival. The receiving device keeps files in memory until you save them, so very large files may not fit.

    Scanning a QR code inside the page only works in browsers that have a barcode detector, such as Chrome on Android and macOS. Elsewhere, scan with the camera app, or copy and paste the code.
